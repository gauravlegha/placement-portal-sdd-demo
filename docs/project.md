# Project Overview: Campus Placement Portal

## 1. System Description
A role-based web application built with Flask and SQLite that facilitates campus recruitment activities. It connects the Institute (Admin), Companies, and Students in a single centralized platform.

## 2. Core Architecture
* **Backend:** Python / Flask
* **Database:** SQLite (managed via SQLAlchemy)
* **Frontend:** Jinja2 Templates + Bootstrap CSS

## 3. Current Feature Context
We are extending the `Student` module. The core portal already supports user registration, profile management, and applying for placement drives. The current initiative is to add an automated Applicant Tracking System (ATS) score to the Student Dashboard to help users optimize their resumes prior to applying.
